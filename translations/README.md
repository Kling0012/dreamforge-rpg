# Translations / 翻訳 / 翻译

This folder holds community translations of Dreamforge RPG.

- `template.json`: every English text the mod shows, updated with each release.
- `COVERAGE.md`: how much of each language is translated.
- `<code>.json`: one file per language (for example `fr.json`).

To add or improve a language, read the [translation guide](../docs/TRANSLATING.md).

ほかの言語の翻訳を置くフォルダです。手順は [翻訳ガイド](../docs/TRANSLATING.md)（英語、末尾に日本語の概要）を見てください。

这里存放社区翻译。步骤请参阅 [翻译指南](../docs/TRANSLATING.md)（英文，末尾有中文概要）。
