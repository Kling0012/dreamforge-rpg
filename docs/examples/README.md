# Example declarations / 宣言の見本

**English**

These files rebuild two built-in travelers with the Hero Connector (see [MODDING.md](../MODDING.md)). They were exported from Dreamforge and re-registered under the keys `Hero_ExampleVesper` and `Hero_ExampleBismuth`; every star matches the original.

- `vesper.dreamforge.json`: 888 of Vesper's 892 stars. The 4 expedition-training stars cannot be declared.
- `bismuth.dreamforge.json`: all 747 of Bismuth's stars.

Use them as a reference for the format and for the built-in star IDs you can copy with `authoredEffect`. They are not meant to be installed as they are. The extended fields need the first Dreamforge release after v3.8.85.

**日本語**

ヒーローコネクタ（[MODDING.ja.md](../MODDING.ja.md)）で、既存の旅人2人の星図を組み直した見本です。Dreamforge から書き出し、`Hero_ExampleVesper` と `Hero_ExampleBismuth` の名前で登録し直して、すべての星が元と一致することを確かめています。

- `vesper.dreamforge.json`: ヴェスパーの892星のうち888星。遠征の鍛錬の4星は宣言できません。
- `bismuth.dreamforge.json`: ビスマスの747星すべて。

形式と、`authoredEffect` で複製できる既存の星の ID を確かめるための見本です。そのまま入れて使うものではありません。拡張の欄を使うには、v3.8.85 の次のリリース以降の Dreamforge が必要です。
